# PTS Static Pages

This repository contains static HTML pages for PTS, maintained fully in English for allied and commercial partners. The current pages include:

- `about.html` — procurement credentials (NSPA, NCAGE 022CJ, UEI Z1VDMSSCTGKS, active SAM.gov) and Estonia-based global delivery details.
- `contact.html` — an operational contact form with communication preferences and compliance-focused footer, capturing every detail in English.

All pages are plain HTML/CSS for straightforward hosting or integration.
